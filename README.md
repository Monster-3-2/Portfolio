# Sankil Sudrik - AI/ML Engineer Portfolio

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Visit: http://localhost:5173

### 3. Deploy to Vercel
```bash
git init
git add .
git commit -m "My portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sankil-portfolio.git
git push -u origin main
```

Then go to vercel.com → Import → Select repo → Deploy

## 📦 What's Inside
- React 18 with Vite
- Framer Motion for animations
- Tailwind CSS for styling
- Lucide React for icons
- 3D Avatar with magnetic hover effect
- Responsive design (mobile to desktop)

## 📝 Customization
Edit `src/App.jsx` to change:
- Name, title, bio
- Contact information
- Projects
- Skills
- Experience
